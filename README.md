# AEROVIA Climate Solutions

A professional e-commerce storefront concept for air conditioners, mini splits, portable AC units, window AC, heat pumps, HVAC equipment, accessories and climate-control solutions.

## Included
- Responsive storefront homepage
- Realistic local product and category imagery
- Search and category filtering
- Price sorting
- Wishlist with LocalStorage
- Shopping cart with LocalStorage
- Climate Finder
- Support/contact form
- Support email, phone and location
- Responsive mobile layout
- Optimized local assets
